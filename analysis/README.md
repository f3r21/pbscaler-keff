# analysis/

Análisis descriptivo de los runs (genera las tablas y figuras de Cap_4). Los scripts reales
viven en `instrumentation/`.

**Política:** sin estadística inferencial. Se reporta **N=3**, **mediana + rango (mín, máx)** y
comparación cualitativa de medianas (`Cap_3:274-275`). Sin p-values, intervalos de confianza,
ANOVA ni pruebas no paramétricas — justificación en `Cap_3:289` (Wohlin §8.1.2/§8.3.2: la mediana
y el rango son válidas para N pequeño con alto coste por ejecución).
